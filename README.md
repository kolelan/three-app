# 3D Арена

Браузерная 3D-арена на **Three.js**: настраиваемый рельеф, лабиринт, враги, шесть типов оружия, режим дальнего боя и учёт побед по баллам (сохраняются в браузере).

Весь код игры сосредоточен в одном файле [`web/index.html`](web/index.html) (~3700 строк). Логические **компоненты** — это именованные блоки функций и DOM-секции внутри этого файла (см. [документацию](docs/README.md)).

## Быстрый старт

### Требования

- Современный браузер с поддержкой ES-модулей и WebGL
- Локальный HTTP-сервер (модули Three.js не открываются через `file://`)

### Запуск

```bash
# из корня репозитория
cd web
npx --yes serve .
# или: python -m http.server 8080
```

Откройте в браузере адрес сервера (например `http://localhost:3000`), нажмите **«Начать игру»**.

### Управление

| Действие | Клавиши / мышь |
|----------|----------------|
| Движение | `W` `A` `S` `D`, `Q` / `E` — стрейф |
| Прыжок | `Пробел` — в т.ч. отскок от пола лабиринта (стоя на плите или при падении на неё) |
| Смена оружия | `1`–`7` или `B` (по кругу) |
| Дальний бой | `G` — прицел (только **первое лицо**), `WASD` — наводка, `Q`/`E` — медленный шаг вбок, колесо — кратность |
| Вид сзади | `V` — 3-е лицо (простая модель игрока), колесо — приблизить/отдалить камеру |
| Рестарт / настройки | `R` |
| После победы | Экран «Победа» → `Продолжить` / ЛКМ / `Пробел` — искать светящуюся дверь в стене → следующий уровень |
| Атака | `ЛКМ` (удержание — огнемёт) |
| Доп. действие | `ПКМ` — импульс / метка / мина |

Подробнее: [docs/weapons.md](docs/weapons.md), [docs/ui-components.md](docs/ui-components.md).

## Оружие (кратко)

| Слот | Название | ЛКМ | ПКМ |
|------|----------|-----|-----|
| 1 | Стандарт | Выстрел | Импульс |
| 2 | Винтовка | Быстрый выстрел | — |
| 3 | Ракетница | Удар по метке | Метка |
| 4 | Мины | Подрыв | Установка |
| 5 | Огнемёт | Удержание — урон | — |
| 6 | Лазер | Зарядка и луч | — |
| 7 | Телепорт | Прыжок на метку | Метка (в небо — прилёт сверху) |

Режим **G** доступен для всех слотов.

## Разработка

### Как вносить изменения

1. Найдите модуль в [карте функций](docs/architecture.md#карта-логических-модулей).
2. Правьте соответствующий блок в `web/index.html`.
3. Перезагрузите страницу (сборки нет).

### Планируемое разбиение (опционально)

Сейчас монолит удобен для прототипа. При росте проекта логические компоненты из `docs/` можно вынести в:

- `web/js/world/` — террейн, лабиринт, спавн
- `web/js/combat/` — оружие, пули, взрывы
- `web/js/ui/` — HUD и setup-panel
- `web/css/game.css` — стили из `<style>`

Контракты (имена функций и `userData`) описаны в документации.
